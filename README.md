Código y material suplementario para la resolución de la ecuación de Smoluchowski mediante malla Lin-Log
# Resolución Numérica de la Ecuación de Smoluchowski (Modelo Híbrido Lin-Log)

Este repositorio contiene el código fuente y el material gráfico suplementario correspondiente al artículo presentado en las JAIIO / SIMS.

## Contenido del Repositorio

* **Códigos en Scilab que implementa la resolución del sistema para el caso difusivo utilizando un método de Runge-Kutta de cuarto orden (RK4) sobre una malla adaptativa.
* **`Fig1_Lineal.png`**: Diagrama de flujo detallado del metodo clasico de resolucion
* **`Fig2_Log.png`**: Diagrama de flujo detallado del metodo de resolucion desarrollado en el trabajo.
* **`Fig3_DLog.pdf`**: Diagrama de bloques algorítmico mostrando el calculo de las diferenciales.

## Requisitos
Para ejecutar el simulador se requiere [Scilab](https://www.scilab.org/) (probado en la versión X.X).
